# Hi3516DV300 串口测试指令手册（agent_test v5 · llm_stream 流式版）

适用固件：含 `/bin/agent_test`（开机自启，综合控制台）、`/bin/llm_test`、`/bin/customer_test`、
`/bin/wifi_cli`、`/bin/llm_ask`（后两者为原 app_test 组件的一次性命令，仍可用）。
串口 **115200 8N1**；终端发送必须带回车换行（SSCOM/XCOM 勾选"发送新行"）。
热点示例：`123456`，密码 `20010504`（下文以此为例）。

---

## 0. 三种调试入口（先分清在哪敲命令）

| 场景 | 操作 | 提示符 |
|---|---|---|
| **agent_test 应用控制台**（最常用） | 上电自启，直接敲命令；若已退出，系统 shell 下 `./bin/agent_test` 重进 | 无特殊前缀 |
| **llm_test 库级验收控制台** | 系统 shell 下 `./bin/llm_test` | `llm> ` |
| **OHOS 系统 shell** | agent_test 里敲 `exit`（或 `quit`）退出即回 | `OHOS #` |

敲 `help` 无反应时依次检查：① 终端勾选"发送新行/加回车换行"；② 波特率 115200；
③ COM 口是否选对。`ls /bin` 可列出全部可用程序。

---

## 1. 标准测试流程（连 WiFi → 流式问答，每条独立执行）

```
ip                  ← 1. 看 WiFi 状态（显示 IP = 已在线，跳到第 4 步）
apx 123456 20010504 ← 2. 连热点（掉线守护自动重连，一般只需一次）
wait 30             ← 3. 阻塞等拿 IP（打印 wlan0 = x.x.x.x 即成功）
ask hello           ← 4. 流式问答（正文逐字打字机冒出）
```

之后重复第 4 步即可不断提问。**流式判据**：回答收尾打
`[llm] 完成 N 字, 耗时 Xs` = 走了流式通道；若打 `[llm] 云端应答` 且整段一次涌出 =
走了 raw 非流式通道（提问超 1KB 时的自动切换，属预期行为，不是故障）。

## 2. agent_test 控制台命令总表（27 条，源码 app_main.c 权威表）

### WiFi（3 条）
| 指令 | 说明 |
|---|---|
| `ip` | WiFi 状态（IP/是否在线） |
| `apx <热点> <密码>` | 连接热点（掉线守护自动重连），例：`apx 123456 20010504` |
| `wait [秒]` | 阻塞等拿 IP，默认 20 秒 |

### LLM 直问（2 条，纯问答，不带动表情/动作）
| 指令 | 说明 |
|---|---|
| `ask <内容...>` | 问 LLM（ASCII 直接敲），例：`ask 请用300字介绍一下你自己` |
| `uni <码点...>` | 问 LLM（**中文推荐**），每参数一个 4 位 Unicode 码点，例：`uni 4f60 597d` = 你好 |

### 智能体对话（2 条，走四行协议，回答时自动切表情/做动作）
| 指令 | 说明 |
|---|---|
| `chat <文字...>` | 和大模型对话（ASCII） |
| `chatu <码点...>` | 中文对话（码点），用法同 `uni` |

> chat 链路的消息超 1KB 会自动转 raw 通道（收尾打 `云端应答`）——智能体长提示词
> 实测约 2.3KB，超 1KB 属正常，见 §3 说明。

### 舵机 / Otto 机器人（13 条）
| 指令 | 说明 |
|---|---|
| `scan [bus]` | 扫描 I2C 总线器件 |
| `pinit [bus] [addr]` | 初始化 PCA9685 |
| `pstatus` | PCA 就绪态（本进程视角） |
| `angle <ch> <deg>` | 单舵机角度 0~180（ch 0~15），例：`angle 0 90` |
| `us <ch> <us>` | 单舵机脉宽 500~2500 |
| `run <动作> [参数...]` | 阻塞执行动作，例：`run walk 2 800 1 0` |
| `post <动作> [参数...]` | 后台执行动作（`stop` 可中止） |
| `stop` | 中止当前动作 + 清空队列并归位 |
| `off` | 中止 + 全通道停脉冲（舵机失力） |
| `list` | Otto 动作表（可执行的 `<动作>` 名以此为准） |
| `map` | 肢体通道映射 |
| `pose` | 当前姿态 |
| `trim <ll..rh\|0~5> <-50~50>` | 肢体微调（度） |

### 按键 / 语音（3 条）
| 指令 | 说明 |
|---|---|
| `key` | 按键状态（自启已停用，按键移交 ui_display） |
| `voice start\|stop\|status` | 语音唤醒 + 三段式对话（默认开机自启） |
| `vol [0~100]` | 播放音量（不带参数查看；0=静音） |

### 其它（4 条）
| 指令 | 说明 |
|---|---|
| `help`（`?` 同） | 本帮助（按分组打印） |
| `ver` | 版本信息 |
| `quit` / `exit` | 退出程序，回到系统 shell |

## 3. 中文输入方法（串口敲不了中文时）

1. 打开 Unicode 码点查询（或用转换工具把中文转成 UTF-16 码点）；
2. 每个字一个 4 位 hex 码点、空格分隔：
   - `uni 4f60 597d` → LLM 直问"你好"
   - `chatu 4f60 597d` → 智能体对话"你好"
3. 常用字速查：你=4f60 好=597d 讲=8bb2 笑=7b11 话=8bdd 天=5929 气=6c14。

串口工具（SSCOM 等）若支持 UTF-8 发送，也可在发送区直接输入中文发给 `ask`。

## 4. llm_test 控制台（llm_stream 库级验收，`./bin/llm_test` 进入）

先敲 `help` 看总览。**注意：agent_test 内置了 key，llm_test 默认 key 为空**，
直连网关前必须先 `gw set key sk-xxx`。

### gw 组（直连网关，流式）
| 指令 | 说明 |
|---|---|
| `gw`（或 `gw show`） | 显示当前网关参数 |
| `gw set ip\|vhost\|port\|key\|model <值>` | 改网关参数，例：`gw set key sk-xxxx` |
| `gw chat <消息>` | **流式问答**（打字机输出，收尾 `[gw] done N chars (Xs)`；失败 `[gw] FAIL 负数 (说明)`），消息省略时会追问 `msg>` |
| `gw direct <ip> <vhost> <port> <key> <model\|-> [msg]` | 一次性指定五要素直连流式问答（model 传 `-` 用库默认） |

默认网关：`47.102.215.139` / `api.siliconflow.cn` / 模型 `deepseek-ai/DeepSeek-V4-Flash`。

### relay 组（中继转发，非流式）
| 指令 | 说明 |
|---|---|
| `relay` | 查看中继地址（默认 192.168.1.1:8443） |
| `relay set <ip> <port>` | 改中继地址 |
| `relay reset` | 恢复默认 |
| `relay ask [msg]` | 经中继问 LLM（走 `llm_ask` 非流式接口，整段返回） |

### wifi 组（llm_test 内自带 WiFi 操作）
子命令：`conf/connect/ap/daemon/ip/wait/creds/demo`，敲 `wifi help` 看用法。
典型：`wifi ap 123456 20010504` → `wifi wait 30` → `wifi ip`。

### uart 组（串口透传桥）
子命令：`list/open/baud/send/rx/mode/bridge/close/status`。
典型：`uart open 1 9600` 打开 /dev/uartdev-1，`uart bridge` 进入透传（**Ctrl+] 退出**）。

### 其它
| 指令 | 说明 |
|---|---|
| `errs` | 错误码表（FAIL 时对照） |
| `show` | 网关参数速览 |
| `ver` | 版本（llm_test 1.3） |
| `quit` / `exit` | 退回系统 shell |

## 5. 一次性命令（系统 shell 下，不必进 agent_test）

原 app_test 组件提供的独立小程序，适合脚本化冒烟测试：

| 指令 | 作用 |
|---|---|
| `exec /bin/wifi_cli apx <热点> <密码>` | 连接指定热点（写配置+起守护） |
| `exec /bin/wifi_cli connect [conf路径]` | 用已有 wpa 配置连接 |
| `exec /bin/wifi_cli wait [秒]` | 阻塞等拿 IP，默认 20 秒 |
| `exec /bin/wifi_cli status` | 查询 IP 状态（返回 0 = 在线） |
| `exec /bin/llm_ask hello world` | 问 LLM（ASCII 多参数空格拼接，非流式整段返回） |
| `exec /bin/llm_ask uni 4f60 597d` | 中文码点模式 |
| `exec /bin/llm_ask hex e4bda0e5a5bd` | UTF-8 字节 hex 模式（连写不加空格） |

## 6. 语音链路观察点（开机自启，一般无需敲指令）

| 观察项 | 含义 |
|---|---|
| `[recv] xxx (N bytes)` | 语音 WebSocket 事件到达（speech_stopped/committed/response.created/…） |
| `[You] …` | 你的语音 ASR 转写 |
| `[AI] …` | AI 回复转写（随 `response.audio_transcript.delta` 逐段出现 = 流式） |
| `[latency] speech-stop/committed/response-created -> first-play: xxx ms` | 首播延迟（约 400ms 量级为正常） |
| `response.audio.delta (N bytes)` | 音频块边收边播 |
| `[Func]:hi_mpi_vb_get_block_vir_addr ... illegal!` | 海思 MPP 后台告警，与业务无关，可忽略 |

语音开关/音量：`voice status`、`voice stop`、`voice start`、`vol 80`。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 敲命令无回显无反应 | 终端勾"发送新行"；波特率 115200 8N1 |
| 想敲中文 | 用 `uni`/`chatu` 码点模式（§3） |
| `ask` 收尾打"云端应答"而非"完成 N 字" | 提问超 1KB 自动走 raw 通道，预期行为；短问即流式 |
| `gw chat` 提示 key empty | 先 `gw set key sk-xxx`（agent_test 内置 key，无需此步） |
| WiFi 掉线 | `apx 123456 20010504` 重连（守护平时自动重连）；系统 shell 可 `exec /bin/wifi_cli status` 查看 |
| 回答中途出现 hi_mpi 告警 | 后台语音/媒体模块日志串扰，忽略 |
| 问答无响应且报 FAIL 负数 | `llm_test` 里敲 `errs` 对照错误码；先 `ip` 确认在线 |
